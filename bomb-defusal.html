Defusal Manual

The bomb-holder cannot read this manual. They describe what they see. The expert reads the rules and guides them.

Rotate the bomb to see the back face — it shows the serial number, battery count, indicator lights, and ports.

Serial Number

A 6-character code. Does it end in an odd digit? Does it contain a vowel (A E I O U)?

Indicators

Small labeled lights — either lit (glowing) or unlit. Some modules reference specific indicators like FRK or CAR.

Batteries & Ports

Visible on the back. Battery count affects The Button module.

Modules

  • Wires — Cut exactly one wire.
  • The Button — Tap or hold based on color/label.
  • Keypad — Press 4 symbols in the correct order.
  • Simon Says — Repeat flashing color sequences.
  • Memory — 5-stage button memory challenge.
  • Morse Code — Decode blinking light, type the word.

Wires

3–6 colored wires. Cut exactly one. Wire 1 = top.

3 Wires

  • No red wires → cut wire 2.
  • Last wire is white → cut wire 3.
  • More than one blue → cut wire 3.
  • Otherwise → cut wire 3.

4 Wires

  • More than one red AND serial ends odd → cut last red wire.
  • Last wire yellow AND no red → cut wire 1.
  • Exactly one blue → cut wire 1.
  • More than one yellow → cut wire 4.
  • Otherwise → cut wire 2.

5 Wires

  • Last wire black AND serial ends odd → cut wire 4.
  • Exactly one red AND more than one yellow → cut wire 1.
  • No black wires → cut wire 2.
  • Otherwise → cut wire 1.

6 Wires

  • No yellow AND serial ends odd → cut wire 3.
  • Exactly one yellow AND more than one white → cut wire 4.
  • No red → cut wire 6.
  • Otherwise → cut wire 4.
"Last red wire" = lowest-numbered red wire, top to bottom.

The Button

Apply rules in order — first match wins.

Tap (press & release quickly)

  • More than 1 battery AND label says DETONATE → tap.
  • Red button AND label says HOLD → tap.

Hold (press & hold)

  • Blue button AND label says ABORT → hold.
  • Yellow button → hold.
  • Otherwise → hold.

Releasing a Held Button

A colored strip lights up while holding. Release when the timer contains:

  • Green → timer shows a 5
  • Yellow → timer shows a 3
  • Any other → timer shows a 1
Check battery count on the back of the bomb.

Memory

Display shows 1–4. Four buttons show numbers in some order. 5 stages. Track pressed position (1=left→4=right) and label.

Stage 1

  • Display 1 or 2 → position 2.
  • Display 3 → position 3.
  • Display 4 → position 4.

Stage 2

  • Display 1 → label 4.
  • Display 2 → same position as stage 1.
  • Display 3 → position 1.
  • Display 4 → same position as stage 1.

Stage 3

  • Display 1 → same label as stage 2.
  • Display 2 → same label as stage 1.
  • Display 3 → position 3.
  • Display 4 → label 4.

Stage 4

  • Display 1 → same position as stage 1.
  • Display 2 → position 1.
  • Display 3 → same position as stage 2.
  • Display 4 → same position as stage 2.

Stage 5

  • Display 1 → same label as stage 1.
  • Display 2 → same label as stage 2.
  • Display 3 → same label as stage 4.
  • Display 4 → same label as stage 3.
Wrong = strike and restart from stage 1.
